# Web Video Downloader

HTML, Tailwind CSS, and JavaScript site for Netlify.

The page asks a Netlify Function for a direct file link. Only save videos you made or have permission to save. It does not unlock paid or protected videos.

## Put it on Netlify

1. Open https://app.netlify.com/start/deploy?repository=https://github.com/Glitchplays1/web-video-downloader
2. Sign in and deploy this repository.
3. Wait until the site says it is published, then open the Netlify URL and paste a video link.

Build settings are already in `netlify.toml`: publish folder `public`, function folder `netlify/functions`.
